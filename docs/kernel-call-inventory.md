# Kernel Call Inventory

> The **numbers** in this document are generated by
> `tools/gen-call-inventory.ps1`, which greps `src/` for `jsr`/`jmp` against the
> resident-kernel jump-table names below, plus the known local-name aliases (see
> [Methodology](#methodology)). The prose around them is hand-written. Never
> hand-edit a count — `tools/verify-inventory-docs.ps1` fails when one no longer
> matches the tree, and the generator rewrites them all in one pass.
>
> ⚠️ **Count the aliases with their targets.** A literal grep for
> `jsr kSyscall` finds 1 call: `tools/assemble-tasks.asm` defines
> `.const syscall = kSyscall`, and essentially every task calls it as
> `jsr syscall`, not `jsr kSyscall`. Folding those in puts `kSyscall` in
> **first place (190 calls)**. See the aliasing note in Methodology.

## Methodology

**Scope: resident kernel only, not libraries.** GordonOS's public API lives at
one flat jump table, `$E000+` (plus a handful of pocket stubs elsewhere),
declared in [`src/kernel/jumptable.inc`](../src/kernel/jumptable.inc) as `k*`
constants. Every task imports that file and calls kernel routines by name
(`jsr kPrintChar`, etc.). But not all of those entries are actually resident:

- Most `kXxx:` labels in [`src/kernel/kernel.asm`](../src/kernel/kernel.asm)
  (and the entries pinned by
  [`src/main.asm`](../src/main.asm)) `jmp` straight to a routine implemented
  in `src/kernel/*.inc` — always loaded, always resident. These are what this
  document inventories.
- Second group `jmp libStub*` or `jmp libTrap`. Those are cold dispatch
  stubs for **libraries** under `src/libs/` (`time`, `filesys`, `gfx`, `fp`,
  `string`, `sid`, `ipc`, `sprite`) — the routine only exists once the
  library is paged in, and the jump-table slot gets warm-patched at load
  time (for an eagerly-loaded library, `libTrap` is the shared "you forgot
  to declare this library" fail-safe). `sprite.lib`'s four stubs live in
  [`src/kernel/sprite.inc`](../src/kernel/sprite.inc) rather than
  `kernel.asm`, because that file owns the shadow block they index. These
  are excluded here because this document inventories resident-kernel calls,
  not library calls: `kStrlen`, `kStrcpy`,
  `kByteToHex`, `kGetTime`, `kSetTime`, `kPrintTime`, `kSkipSpaces`,
  `kHexDigit`, `kNibbleToHex`, `kReuFormat`, `kReuDirEntry`, `kReuSave`,
  `kReuDelete`, `kReuRename`, `kPlot`, `kLine`, `kBox`, `kFillBox`, `kCircle`,
  `kEllipse`, `kFloodFill`, `kGetPixel`, `kClearBitmap`, `kSetGfxColor`,
  `kGfxChar`, `kGfxString`, `kReuCreate`, `kReuOpen`, `kReuReadAt`,
  `kReuWriteAt`, `kStrcmp`, `kFillMatrix`, `kFpCall`, `kSidPlay`, `kSidHush`,
  `kIpcPost`, `kIpcPick`, `kSpriteSheet`, `kSpriteFrame`, `kSpritePos`,
  `kSpriteReg`.

That leaves **60 resident kernel entry points** — the `k*` constants in
`jumptable.inc` whose `kernel.asm` (or `main.asm`) target is a real resident
label, including the helper entries explicitly marked `(resident)` in the
source comments (`kReuDirPageDma`, `kReuCmpName`, `kReuFindFile`,
`kSurfDisplayed`), the collision call `kSpriteCollide`
(`src/kernel/sprite.inc`), and
`kLibHold` (library-system machinery, not a library call itself).

**Finding call sites.** For each of the 64 names, searched `src/**/*.asm` and
`src/**/*.inc` for `jsr <name>` / `jmp <name>`, excluding full-comment lines
(`jumptable.inc`'s own usage examples, doc comments elsewhere) and the
`kName: jmp <target>` definition lines themselves (those name the *target*,
not `kName`, so they don't match). A line may carry more than one call —
`jsr kNewline; jsr kNewline` is two — and each is counted, so these are
**call sites**, not lines. Library **source** files (`src/libs/*`)
are included as callers where relevant — a library still calls resident
kernel routines like any other code, it's only the library's own entry
points that were excluded above.

**Two aliasing wrinkles — both folded into the counts below:**

- `tools/assemble-tasks.asm` (the harness every task source is compiled
  through) defines `.const syscall = kSyscall`, "old task sources use the
  internal name". Every task calls it as `jsr syscall` — 154 sites across
  35 files — and none spells the `kSyscall` name directly.
- `src/tasks/dynamic/basic.asm` defines `.const csrBoth = kCsrBoth` and
  calls it as `jsr csrBoth` from `basicedit.inc` (3 sites) — same target
  address as `kCsrBoth`.
- `kAllocBitmap`/`kFreeBitmap` are `.const` aliases of `kAllocScreen`/
  `kFreeScreen` (both names reach the same routine) — they are **not** entries
  here, and the two `kAllocBitmap` call sites are counted under `kAllocScreen`.

Checked via `.const <name> = k[A-Z]...` across all of `src/` and
`tools/assemble-tasks.asm`; these two are the only such aliases. **Excluded**
(deliberately, not missed): kernel-internal calls that bypass the jump table
and call the real label directly — e.g. `src/kernel/dynload.inc` and
`src/kernel/semaphore.inc` also call `jsr syscall` internally (the actual
`syscall:` label in `syscall.inc`, same one `kSyscall` jumps to), and
`src/kernel/keyboard.inc` calls `jsr csrBoth`/`jsr printChar` directly. Those
are implementation reuse inside the resident kernel, not calls to the `k*`
API surface this document is inventorying.

## Summary

- 60 resident kernel entry points in scope (the `k*` jump-table
  constants in `src/kernel/jumptable.inc` whose `kernel.asm` target is a real
  resident routine, not a `libStub*`/`libTrap` library dispatch — see
  [Methodology](#methodology)).
- 53 of them have at least one call site in the current source tree;
  7 have none (listed at the end).
- **1212 total call sites** found across `src/`.

## Resident kernel calls with no current call sites

Part of the public API (defined in `jumptable.inc`, implemented in
`src/kernel/`) but not invoked by any task or kernel file in the current tree.

| Kernel call | Address | What it does |
|---|---|---|
| `kCursorAddr` | `$E042` | Compute the screen RAM address at the current cursor position into `kPtr`, without moving the cursor. |
| `kDynFree` | `$E093` | Free a dynamic task's table entry and any bitmap pages it reserved; a no-op for statically-compiled tasks. |
| `kFreeBitmap` | (alias of `kFreeScreen`) | Free the current task's bitmap slot; a no-op if it isn't a bitmap task. |
| `kGetScrollRegion` | `$E0EA` | Read the current surface's scroll region. |
| `kSetCursorColor` | `$E066` | Set the cursor colour for the current task's surface; picked up by the blink handler on the next toggle. |
| `kSpriteCollide` | `$CDE7` | Read the frame-latched sprite collision masks, and clear them. |
| `kTakeScreenOwnership` | `$E05D` | Transfer full ownership of a shared screen from a source task to the current task. |
| `kViewScreen` | `$E057` | Switch the VIC-II display to another task's screen without taking keyboard focus -- peek without giving up input. |
